# Инструкция по публикации приложения «Москва» в RuStore

## 1. Подготовка файлов

Перед публикацией убедитесь, что у вас есть:
1. **Файл сборки:**
   - Либо `Moskva-release.aab` (рекомендуется RuStore)
   - Либо `Moskva-release.apk`
   *(Оба файла скачиваются из вкладки **Actions -> Artifacts** после сборки на GitHub)*
2. **Иконка приложения:**
   - Файл `store_icon_512.png` (512×512 px) лежит в корне папки `moskva_android_app`.
3. **Скриншоты приложения:**
   - 2–4 скриншота экрана смартфона (можно сделать на телефоне после установки `.apk` или в браузере с мобильным разрешением для `https://mos77.ru/msk/`).

---

## 2. Шаги публикации в консоли RuStore

1. Перейдите в [Консоль разработчика RuStore](https://console.rustore.ru/) и войдите в свой аккаунт.
2. Нажмите кнопку **«Добавить приложение»**.
3. Заполните карточку приложения:
   - **Название приложения:** `Москва`
   - **Пакет приложения (Package Name):** `com.codekon.msk` (определится автоматически при загрузке файла)
   - **Категория:** `Городские сервисы` или `Путешествия и навигация`
   - **Тип:** `Бесплатное`
   - **Возрастной рейтинг:** `12+`

4. Загрузка файла сборки:
   - Выберите вкладку загрузки и прикрепите скачанный файл `Moskva-release.aab` или `Moskva-release.apk`.
   - Система RuStore автоматически проверит цифровую подпись (v1/v2), версию (1.0.0) и целевую версию SDK (34).

5. Графические материалы:
   - **Иконка:** Загрузите `store_icon_512.png`.
   - **Скриншоты:** Загрузите скриншоты разделов афиши, событий и ресторанов.

6. Текстовое описание (готовые шаблоны):

   **Краткое описание (до 80 символов):**
   ```
   Афиша Москвы: куда сходить сегодня, события, театры, парки и выставки.
   ```

   **Полное описание:**
   ```
   «Москва» — ваш персональный гид и актуальная афиша событий столицы.

   Узнайте, куда сходить сегодня, вечером или на выходных:
   • Актуальная афиша событий, выставок, спектаклей и фестивалей
   • Популярные и скрытые достопримечательности города
   • Лучшие рестораны, кафе и гастрономические пространства
   • Парки, музеи, развлечения для всей семьи и детей
   • Удобная навигация, часы работы, контакты и схемы проезда

   Вся культурная и развлекательная жизнь Москвы в одном удобном приложении!
   ```

7. Ссылка на политику конфиденциальности:
   - Укажите ссылку: `https://mos77.ru/` (или прямую ссылку на раздел политики конфиденциальности на вашем сайте).

8. Отправка на модерацию:
   - Нажмите **«Отправить на модерацию»**.
   - Проверка обычно занимает от нескольких часов до 1 рабочего дня.

---

## 3. Выпуск будущих обновлений

Когда потребуется обновить приложение (например, изменить логику или обновить версию сайта):
1. В файле `app/build.gradle` увеличьте версии:
   ```groovy
   versionCode 2
   versionName "1.0.1"
   ```
2. Сделайте `git commit` и `git push`.
3. GitHub Actions автоматически соберет новую версию с той же самой подписью.
4. Загрузите новый `.aab` / `.apk` в RuStore в раздел «Версии» -> «Новая версия».
