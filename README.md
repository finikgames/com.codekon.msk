# Приложение «Москва» (com.codekon.msk) — WebView для RuStore

Нативное Android WebView приложение для портала [mos77.ru/msk/](https://mos77.ru/msk/) («Куда сходить в Москве: Афиша, События, Развлечения»), полностью подготовленное для публикации в **RuStore** с автоматической сборкой и релизной подписью через **GitHub Actions**.

## ✨ Возможности и соответствие требованиям RuStore

1. **Полноценный WebView клиент**:
   - Включена поддержка JavaScript, DOM Storage, LocalStorage, IndexedDB.
   - Оптимизированный User-Agent (`MoskvaApp/1.0.0 (Android; RuStore)`).
   - Поддержка Cookies и сессий.
   - Hardware Acceleration включена для максимальной плавности.
2. **Экран при отсутствии интернета**:
   - При сбое сети или отсутствии подключения отображается аккуратный экран ошибки с кнопкой «Повторить попытку» вместо стандартной ошибки браузера.
   - Автоматическое восстановление и перезагрузка при появлении интернета (`ConnectivityManager`).
3. **Навигация**:
   - Корректная обработка кнопки «Назад» (переход назад по страницам сайта, при достижении главной — двойной тап для выхода с предупреждением).
   - Внутренние ссылки `mos77.ru` открываются внутри приложения.
   - Спец-схемы (`tel:`, `mailto:`, `tg:`, `whatsapp:`, `intent:`, `geo:`) открываются в соответствующих нативных приложениях.
   - Внешние сайты открываются в системном браузере.
4. **Загрузка файлов (`<input type="file">`)**:
   - Реализован `WebChromeClient.onShowFileChooser` для загрузки фото и документов.
5. **Геолокация**:
   - Запрос разрешений на доступ к местоположению для интерактивных карт и афиши событий рядом.
6. **Pull-to-Refresh & Индикатор**:
   - Обновление страницы свайпом вниз (`SwipeRefreshLayout`).
   - Тонкий стильный индикатор загрузки сверху (`LinearProgressIndicator`).
7. **Иконки**:
   - Фирменная иконка «Москва» адаптирована под все плотности экранов (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi) в квадратном и круглом форматах.
   - В корне проекта подготовлен файл `store_icon_512.png` (512×512 px) для загрузки в консоль RuStore.

## 🚀 Сборка через GitHub Actions

В репозитории уже настроен рабочий процесс `.github/workflows/build.yml`.

### Как запустить сборку:

1. Создайте репозиторий на [GitHub](https://github.com/new).
2. Загрузите файлы проекта в ваш GitHub-репозиторий:
   ```bash
   cd "moskva_android_app"
   git init
   git add .
   git commit -m "Initial commit for Moskva RuStore app"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
3. После пуша откройте вкладку **Actions** в вашем репозитории на GitHub:
   - Процесс `Build Moskva RuStore Release` запустится автоматически.
   - Сборка занимает ~2-3 минуты.
4. По завершении сборки в блоке **Artifacts** будут доступны для скачивания:
   - **`Moskva-Release-APK`** — готовый подписанный `.apk` файл для установки и тестирования.
   - **`Moskva-Release-AAB`** — готовый подписанный `.aab` файл (Android App Bundle) для публикации в RuStore.
   - **`Keystore-Backup`** — резервная копия ключа подписи.

### Опционально: Использование GitHub Secrets
Если вы не хотите хранить `release.keystore` в открытом коде (или репозиторий публичный), вы можете добавить следующие секреты в **Settings -> Secrets and variables -> Actions**:
- `KEYSTORE_BASE64` — base64-строка ключа (содержимое `release.keystore`)
- `KEYSTORE_PASSWORD` — `moscow2024`
- `KEY_ALIAS` — `codekon`
- `KEY_PASSWORD` — `moscow2024`
